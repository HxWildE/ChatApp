Got it—Blue + Black theme finalized. Here’s a clean, structured set of color collections with hex codes mapped to UI roles so you can drop them straight into your React app:

🎨 Blue + Black Theme Collections
🌑 Base Layer
Primary Background: #0D0D0D (deep black)

Secondary Background: #1C1C1C (dark gray for panels/cards)

Surface/Chat Bubble (User): #1E90FF (Dodger Blue)

Surface/Chat Bubble (Other): #0A3D62 (navy blue)

✨ Text
Primary Text: #FFFFFF (white, high contrast)

Secondary Text: #B0B0B0 (light gray for timestamps, metadata)

Disabled/Muted Text: #666666

🔔 Status & Feedback
Success: #2ECC71 (green, optional for online/confirmed states)

Warning: #FF8C00 (orange, sparingly for alerts)

Error: #E74C3C (red, reserved for errors)

Notification Badge: #FFD700 (yellow, small highlights only)

🎯 Interactive Elements
Primary Button/CTA: #00BFFF (cyan blue, stands out against black)

Hover State: lighten blue → #33CCFF

Active State: darker blue → #007ACC

Border/Divider: #2A2A2A (subtle separation without clutter)
